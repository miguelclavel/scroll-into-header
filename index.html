Scroll. The name doesn't fade out and reappear up there. It travels.

Parked.

One number between 0 and 1, how far you are through the tall section, drives everything: the size of the name, where it sits, and how much the rest fades. It's bent through an ease out curve before it's used, because straight lines feel mechanical.

The nice part is you can tune it forever by changing one number. Code and prompt.
